# Travel Fare Calculator

## Description
This program calculates the total fare price

## Version 1 - Original code without input validation
- Input: Accepts the passengers name, distance of ride and number of passengers.
- Process: Calculates and displays the price of the fare.
- Output: Fare price.
- Does not include input validation.
  
## Version 2 - Updated code with input validation
 - Input: Accepts the passengers name, distance of ride and number of passengers.
-  Process: Validates the input, then calculates and displays the price of the fare.
-  Output: Fare price or error message if input is invalid.
-  Includes input validation, displays the passenger name with the error message if the numbers are the only ones invalid .
